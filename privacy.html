プライバシーポリシー（shorts-watch）

shorts-watch は、YouTube チャンネル「ばずにゅー」の運営者が自分のチャンネルを分析するための個人用のツールです。

1. 取得する情報

Google アカウントで許可を受けたうえで、運営者自身のチャンネルについて次の情報を読み取ります。

  • YouTube アナリティクスの数字（動画ごとの再生回数・視聴時間・視聴維持率・流入元・高評価・共有・登録者の増減など）
  • チャンネル名とチャンネル ID

2. 使い方

運営者が自分の動画の作り方を見直すための分析にだけ使います。広告や、ほかの目的には使いません。

3. 保存

取得したデータと許可の情報は、運営者のパソコンの中だけに保存します。外部のサーバーには送りません。

4. 第三者への提供

取得したデータを第三者に提供・販売することはありません。

5. 許可の取り消し

許可は、Google アカウントの「セキュリティ」→「サードパーティ製のアプリとサービス」からいつでも取り消せます。

6. Google API サービスのユーザーデータに関するポリシー

shorts-watch が Google API から受け取った情報の使用は、Google API サービスのユーザーデータに関するポリシー（限定使用の要件を含む）に従います。
